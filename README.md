# 📖 Overview

Helix AI is a full-stack AI chatbot designed to provide an intuitive and seamless conversational experience. It combines a modern React frontend with a scalable backend and AI model integration to deliver fast, intelligent, and interactive responses.

The application focuses on providing a clean user experience while demonstrating modern full-stack development practices including authentication, API integration, responsive design, and real-time communication.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/Helix-AI.git
```

## Install Frontend

```bash
cd frontend
npm install
npm run dev
```

## Install Backend

```bash
cd backend
npm install
npm run dev
```
